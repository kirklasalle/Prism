Refraction Capabilities

Splitting cognitive engineering tasks down the spectral line into specialized execution profiles.

HEMISPHERE: LEFT // SEGMENT: LOGIC

Analytical Logic & Construction

The Left Hemisphere is configured strictly for logical deduction, code structuring, AST compilation, and tool calling. It enforces code soundness and prevents creative drift from breaking specifications.

  • AST-Aware Refinement: Generates code edits based on syntax tree checks to preserve files and prevent broad overwrites.
  • Algorithmic Validation: Formulates logical proofs and step-by-step reasoning runs before executing shell tools.
  • Sandbox Isolation: Tool actions run inside local subprocesses or Docker containers with timeouts.

Freedom Profiles

Intelligent application and complete accountability enable both individual agility and business governance.

PROFILE: INDIVIDUAL

Individual Freedom & Agility

Enables maximum operational flexibility on local machines. Under the Individual profile, operators can run Tier 2 mutating operations (e.g. executing shell scripts, creating system files, and spinning up container tasks) directly on their workstations.

  • Tier 2 Execution: Run scripts and compile binaries directly.
  • Local Sandbox Access: Fast terminal sessions and local workspace edits.
  • Compact Preamble: Maximizes the LLM token budget for rapid iteration.

PROFILE: BUSINESS

Business Freedom & Compliance

Enables businesses to deploy autonomous intelligence safely without liability. The Business profile enforces strict non-mutating policies, limiting execution strictly to Tier 1 operations (reads, searches) and requiring multi-signature or manual approval for elevated tasks.

  • Physical Restriction: Destructive commands are blocked at the engine level.
  • Domain Matching: Enforces domain-matching constraints on network API traffic.
  • verbatim 10 Laws: Injects the complete text of the 10 Laws into all prompts to prevent drift.

Monitor how efficiently your models think. The LLRE exposes real-time cognitive metrics to help you audit reasoning costs:
