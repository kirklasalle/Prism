Security Disclosure

Report vulnerabilities responsibly and coordinate disclosure with the Prism Refraction maintainers.

Responsible Disclosure

Send security reports through the contact channel with the subject SECURITY REPORT.

Include affected version, reproduction steps, potential impact, and proposed remediation guidance.

Response Expectations

  • Initial acknowledgment target: 3 business days.
  • Triage classification target: 7 business days.
  • Coordinated disclosure window: determined by impact and exploitability.
